# AI ช่วยกรอกทรัพย์: การใช้งานและตั้งค่า

หน้า Local: http://127.0.0.1:5173/sps-internal-admin/ai-property

## วิธีใช้

1. เข้าหลังบ้านด้วยบัญชี admin, super_admin หรือ agent และเปิดเมนู AI ช่วยกรอกทรัพย์
2. แนบรูปบ้านสูงสุด **15 รูป** และ PDF สูงสุด **2 ไฟล์** ต่อชุด ระบบย่อรูปเป็น WebP ทีละรูปก่อนส่ง รูปต้นฉบับรับไม่เกิน 30 MB ต่อไฟล์ PDF ไม่เกิน 4 MB ต่อไฟล์ ขนาดรวมหลังย่อไม่เกิน 6 MB
3. บอก AI ให้แยกแบบบ้าน ราคา พื้นที่ ห้องนอน ห้องน้ำ และแจกแจงของแถม ถ้าไม่พบข้อมูล AI ต้องเว้นช่องไว้และถาม
4. ตรวจแก้ข้อมูลและแหล่งที่มาในแผงด้านขวา เลือกรูปให้ตรงกับแบบบ้าน AI เลือกรูปหน้าปกที่ชัดและเหมาะสม พร้อมเหตุผล คุณเปลี่ยนภาพและข้อความได้
5. กดนำข้อมูลไปกรอกฟอร์ม ระบบย่อไฟล์สำหรับอัปโหลดให้ไม่เกิน 300 KB ต่อรูป รวมถึงภาพหน้าปกพร้อมข้อความ ตรวจทำเล สถานะ และช่องที่ยังขาด ก่อนกดบันทึกด้วยฟอร์มเดิม

## กฎข้อความและราคา

- ชื่อประกาศไม่มีชื่อโครงการ และต้องลงท้ายด้วยทำเล ชื่อโครงการเก็บในช่องแยก
- `price` คือ **ราคาหลังหักส่วนลด** ที่ใช้กรอกช่องราคาประกาศ ถ้าหลายแปลง `priceMax` คือราคาหลังส่วนลดสูงสุดของแบบนั้น
- `bankPrice` คือ **ราคาก่อนหักส่วนลด** ใช้ช่อง “ราคาหน้าสัญญา / ราคาประเมิน (บาท)” ต้องเป็นราคาของแปลงเดียวกับราคาเริ่มต้น ห้ามนำราคาคนละแปลงมาคำนวณ
- `discountAmount` คือส่วนลดเป็นเงินบาทตามเอกสาร ถ้ามีราคาก่อนและส่วนลด แต่ยังไม่มีราคาหลัง ให้คำนวณก่อน − ส่วนลด ถ้ามีราคาหลังแล้วห้ามหักซ้ำ ข้อมูลขัดแย้งต้องให้ผู้ใช้ยืนยัน
- ตัวอย่าง: ก่อนส่วนลด 1,900,000 บาท ลด 250,000 บาท → ราคาประกาศ **1,650,000** และราคาหน้าสัญญา **1,900,000**
- รายละเอียด ของแถม โปรโมชั่น และข้อความบนปก ไม่ใส่ราคาเต็มหรือราคาสุทธิ อาจใช้ช่วงปกปิดเช่น 1.6x–1.9x ล้านบาท ตัวเลขเต็มให้อยู่ในช่องราคาเฉพาะ
- คอมมิชชันเริ่มต้น 3% เปลี่ยนได้ และคงค่าที่เคยกำหนดไว้
- พื้นที่ดินตารางวาแยกจากพื้นที่ใช้สอยตารางเมตร ระบบเดิมเก็บพื้นที่ดินเป็นตารางเมตรจึงแปลง 1 ตารางวา = 4 ตารางเมตรเมื่อส่งฟอร์ม

## รูปหน้าปกและจำนวนรูป

แสดงบ้านเต็มภาพแบบไม่ครอปและเพิ่มแถบข้อความด้านล่าง JPEG ตัวอย่าง 1600×1200 ข้อความใช้ชื่อประกาศกับทำเลและข้อมูลห้อง/พื้นที่ที่มีจริง เมื่อส่งฟอร์มจะย่อเป็น WebP อีกครั้ง

ภาพประกาศที่ทำข้อความใช้ **แทน** รูปหน้าปกต้นฉบับในลำดับแรก จึงมีรูปในประกาศไม่เกิน 15 รูปรวมหน้าปก ต้นฉบับที่แนบยังอยู่ในร่างภายในเครื่อง ส่วนรูปที่เหลือเข้าแกลเลอรีตามที่เลือก หากไม่ต้องการข้อความให้ปิด “เพิ่มข้อความประกาศบนภาพหน้าปก”

ร่างและไฟล์เก็บใน IndexedDB แยกตามบัญชีบนเบราว์เซอร์เครื่องนี้ ไม่ซิงก์ข้ามเครื่อง เมื่อกดส่งจึงส่งข้อมูลผ่านเซิร์ฟเวอร์ไป OpenRouter และผู้ประมวลผล รูปอัปโหลดตามระบบเดิมเมื่อกดบันทึกทรัพย์ PDF ใช้อ่านข้อมูล ไม่ถูกเพิ่มเป็นรูปประกาศ ร่างที่ส่งไปฟอร์มเปิดได้ไม่เกิน 7 วัน

## นโยบายใช้ฟรีเท่านั้น

ก่อนเรียก ระบบดึง catalog ของ OpenRouter และเลือกเฉพาะรุ่น `:free` ที่ราคา prompt/completion/image/request และราคาอื่นที่ระบุเป็นศูนย์ รองรับข้อความ รูปภาพ และ JSON

ให้ความสำคัญกับ MiniMax M3.1 Flash รุ่นฟรีถ้ามี จากนั้น Nemotron 3.5 Super VL, Dots3-Note Preview และ Gemma รุ่นฟรีที่ตรวจพบ หากโมเดลแรกไม่พร้อมหรือโควตาเต็ม จะลองตัวฟรีถัดไป สูงสุด 3 รุ่นต่อข้อความ ไม่เปลี่ยนเป็นรุ่นเสียเงิน

ทุกคำขอตั้ง `provider.max_price` ของ prompt/completion/request/image เป็น 0 ห้ามชื่อโมเดลแบบเสียเงิน PDF ใช้ `cloudflare-ai` ซึ่ง OpenRouter ระบุว่าฟรี ไม่ใช้ค่าเริ่มต้น Mistral OCR ที่มีค่าบริการ ไม่มีบริการสร้างภาพ AI เพิ่มเติม การทำข้อความบนภาพทำในเบราว์เซอร์

ข้อจำกัดโควตาฟรีของ OpenRouter ยังมีผล ระบบภายในจำกัด 30 ข้อความต่อบัญชีต่อวัน (UTC) เว้นอย่างน้อย 10 วินาที บัญชีหรือคีย์ที่ถูกปฏิเสธจะไม่แก้ด้วยการเรียกโมเดลเสียเงิน

ค่าโมเดลฟรีไม่ครอบคลุมค่า Firebase/Firestore/Cloudinary/โครงสร้างพื้นฐานเดิม

## คีย์และการรัน Local

คีย์เก็บเฉพาะ `functions/.secret.local` ซึ่งถูก Git ignore และจำกัดสิทธิ์ไฟล์ ไม่ใส่ใน `VITE_*` ซอร์สโค้ด หรือหน้าเว็บ ถ้าต้องเปลี่ยนคีย์ ให้แก้ไฟล์นี้โดยตรง:

```text
OPENROUTER_API_KEY=ใส่คีย์ของคุณที่นี่
```

ไฟล์ `.env.local` ตั้ง `VITE_USE_AI_EMULATOR=true` เพื่อให้ Vite ติดต่อ Functions Emulator ที่ 127.0.0.1:5001:

```sh
firebase emulators:start --only functions --project sps-property
npm run dev -- --host 127.0.0.1
```

บริการ AI local ตรวจสิทธิ์ผ่านผู้ใช้ Firebase เดิม การรันเฉพาะ Functions ไม่ได้จำลองฐานข้อมูลทรัพย์ และไม่ได้บันทึกทรัพย์ให้เอง ห้ามนำ `.secret.local` ไปเผยแพร่ ถ้า OpenRouter ตอบ `User not found` ให้ตรวจบัญชีและสร้างคีย์ใหม่ ไม่ต้องส่งคีย์ในแชต

## เมื่อต้องการเผยแพร่จริง

เก็บคีย์ใน Firebase Secret Manager (ไม่ใช้ไฟล์ local บนโฮสต์):

```sh
firebase functions:secrets:set OPENROUTER_API_KEY --project sps-property
firebase deploy --only functions:aiPropertyAssistant --project sps-property
npm run build
firebase deploy --only hosting --project sps-property
```

production build จะไม่เชื่อม localhost แม้ตั้ง flag สำหรับ development ไว้ การ deploy ยังต้องใช้สิทธิ์และแพ็กเกจ Firebase ที่รองรับ

node --test functions/ai-property.test.cjs src/features/ai-property/*.test.mjs src/lib/propertyContentRules.test.mjs src/lib/inputFormatting.test.mjs src/lib/propertyManagement.test.mjs
